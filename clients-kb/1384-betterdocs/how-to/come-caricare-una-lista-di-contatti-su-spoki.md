# Come Caricare una Lista di Contatti su Spoki

![](https://i.ytimg.com/vi/AuWbUE5ObvU/maxresdefault.jpg)

In questa guida, esploreremo le tre principali modalità disponibili per caricare una lista di contatti su Spoki. Sia che tu stia lavorando con una lista vuota, importando contatti tramite un file CSV o creando una lista personalizzata attraverso la ricerca avanzata, questa guida ti fornirà tutte le informazioni necessarie per eseguire questi passaggi in modo semplice ed efficace.

### 1. **Caricare una Lista Vuota**

La prima modalità consiste nel creare una lista di contatti completamente vuota, per poi aggiungere manualmente i contatti successivamente. Per questo, basta semplicemente scegliere l’opzione di lista vuota nel pannello di gestione delle liste di Spoki.

### 2. **Importare i Contatti da un File CSV**

Il secondo metodo consiste nell’importare i contatti da un file CSV. Per fare ciò:

- Scarica il file di esempio fornito da Spoki per avere un’idea di come strutturare il tuo file CSV.
- Imposta il tuo CSV con i contatti da caricare, facendo attenzione a mantenere il formato corretto come mostrato nel file di esempio.
- Carica il file CSV su Spoki. Il sistema ti permetterà di associare i vari campi del CSV con i campi di contatto di Spoki, facendo un “matching” tra i dati.
- Verifica il totale dei contatti che verranno importati e scegli se desideri limitare il numero di contatti da caricare nella lista finale. Ad esempio, se hai tre contatti nel CSV, puoi decidere di caricare solo due di essi.
- Generazione automatica delle liste: Se scegli di caricare una selezione di contatti, Spoki creerà automaticamente una lista per te con i contatti desiderati.

### 3. **Creare una Lista con la Ricerca Avanzata**

Il terzo metodo è quello di utilizzare la **ricerca avanzata** all’interno della piattaforma Spoki per creare una lista personalizzata di contatti già presenti nel sistema. In questo caso, puoi selezionare uno o più criteri (ad esempio, la lingua, la posizione o altri attributi) che i contatti devono soddisfare.

- Seleziona i criteri di ricerca desiderati. Ad esempio, se vuoi creare una lista di contatti che parlano inglese, basta selezionare “Lingua: Inglese” nel pannello di ricerca.
- Passa alla creazione della lista: Spoki selezionerà tutti i contatti che soddisfano questi criteri e ti permetterà di trasferirli facilmente nella nuova lista.
- Salva la lista: Una volta completato il processo, troverai la nuova lista di contatti tra quelle disponibili all’interno della piattaforma.

### 4. **Integrazione con CRM e Tool di Marketing**

Nel caso in cui tu stia utilizzando un CRM o un altro strumento di marketing, è possibile **integrare Spoki** con questi sistemi per caricare direttamente i contatti dalle tue piattaforme esterne. In questo modo, risparmierai tempo e semplificherai la gestione delle tue liste.
