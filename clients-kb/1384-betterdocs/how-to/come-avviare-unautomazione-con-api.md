# Come avviare un&#8217;automazione con API

Per avviare un’automazione a partire dallo step di avvio API è necessario:

- Definire e farsi approvare il template che si desidera inviare
- Creare un’automazione con Trigger API

Vai su Automazioni > Nuova > Trigger > Integrazioni > API

![](https://support.spoki.com/wp-content/uploads/2022/12/Screenshot-2025-10-16-alle-14.27.53.png)
Si aprirà una scheda con le informazioni da inserire nell’API. Per tutti i dettagli su come impostare le API è possibile consultare la seguente documentazione API: [Documentazione API](https://documenter.getpostman.com/view/21611004/UzBqnPvF)

Nel caso in cui le API richiamino un Form, per ciascun campo del form dovrete creare un campo dinamico su Spoki in modo che le API possano aggiornare le informazioni del contatto. 

cliccando il pulsante +, potrete selezionare il template da inviare ai contatti e tutte le altre azioni che desiderate.
