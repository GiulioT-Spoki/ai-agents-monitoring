# Integrare Spoki con qualsiasi gestionale attraverso API

Le API di Spoki ti consentono di inviare messaggi su WhatsApp o avviare le automazioni quando vuoi.Consulta o inoltra al tuo sviluppatore la [documentazione ufficiale](https://spoki.it/api-documentation) .

Avvia un’automazione **Spoki** chiamando l’**API**.

- Clicca su Automazioni nel menu
- Vai in alto a destra sul tasto “Nuova”
- Dai un nome alla tua Automazione e clicca su “Salva”
- Premi il tasto “Aggiungi step di Avvio” e seleziona “Integrazione” / “API Url”
- Clicca in basso su “Tua azione automatica”
- In “Tipo azione” seleziona “Template”
- Seleziona il template da inviare e clicca su “Aggiungi”
- Premi su “Salva”
- Copia l’URL dell’API appena generato e chiamalo via API con metodo POST
