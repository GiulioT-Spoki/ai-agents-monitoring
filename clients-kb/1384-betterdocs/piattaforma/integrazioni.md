# Integrazioni

Nel menu integrazioni è possibile consultare tutti gli strumenti con cui Spoki si integra.

![](https://support.spoki.com/wp-content/uploads/2022/12/Screenshot-2025-08-07-alle-10.37.19-1-1024x516.png)
 Le integrazioni, possono essere di due tipi: native oppure derivate.

Le **integrazioni native** permettono di collegare Spoki direttamente all’altro strumento es. WooCommerce, Shopify, Zapier, etc.

Le **integrazioni derivate** permettono di collegare Spoki ad un altro strumento, grazie all’utilizzo di un’integrazione nativa es. Zapier, IFTTT (questo tipo di integrazioni ha in basso a destra l’icona dello strumento che ne permette il collegamento).

Cliccando su ciascuna integrazione, sulla destra appariranno tutte le informazioni dettagliate per poter procedere all’integrazione.

Per quanto riguarda l’utilizzo delle API, trovate la documentazione al [seguente link](https://documenter.getpostman.com/view/21611004/UzBqnPvF) e potete richiedere l’API KEY facendo richiesta direttamente dalla piattaforma: Integrazione > API > Richiedi API Key
