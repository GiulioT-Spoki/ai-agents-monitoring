# AVS ELECTRONICS — Installazione software Bios (myAVSAlarm)

Sorgente: documento «Manuale Bios» 26.05.26. Serve a programmare la centrale ULTRA da PC. Non è il firmware della centrale.

## Due canali di installazione

### 1) Applicazione nativa (consigliata)

- Installare **Bios** come applicazione nativa **myAVSAlarm**.
- Supporto dichiarato: anche **MacOS ARM**.
- Procedura: aprire il **wizard di installazione** e seguire le indicazioni a schermo.

### 2) Estensione Chrome

- L’estensione **non è ricercabile** nel Chrome Web Store (la ricerca nello Store non la trova).
- Installarla **solo** dal **link dedicato** fornito da AVS (non inventare URL in chat).
- Dopo il click sul link dedicato, Chrome mostra il popup **«Aggiungere “Bios myAVSAlarm”?»** → **Aggiungi estensione**.

## Collegamento alla centrale (dal manuale ULTRA)

Programmazione da PC con Bios: USB, LAN TCP-IP, Cloud. Password di accesso TCP/IP-Cloud di fabbrica: **000000** (sei zeri), allinearla a quella del cliente nel software.

Codice di comunicazione (tastiera): abilita USB, diagnostica, Demo, aggiornamento periferiche; di fabbrica **non programmato**.
