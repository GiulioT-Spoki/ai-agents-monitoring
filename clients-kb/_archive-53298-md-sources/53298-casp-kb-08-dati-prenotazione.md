# Dati necessari per la prenotazione

## Regola generale

Per ogni nuova prenotazione devono essere disponibili le informazioni necessarie per identificare correttamente Assistito, prescrizione, prestazioni, luogo del servizio, recapiti, modalità di consegna del referto, data ed eventuali dati organizzativi applicabili.

L’ordine delle domande, il riutilizzo dei dati già disponibili, il numero di domande per messaggio e il momento della creazione dell’appuntamento sono disciplinati dal System Prompt.

Ogni Assistito deve essere gestito separatamente, anche quando più persone effettuano il prelievo nello stesso domicilio.

# Dati obbligatori

Per ogni nuova prenotazione devono essere disponibili:
- nome e cognome;
- codice fiscale;
- recapito telefonico operativo;
- prescrizione amministrativamente gestibile;
- esami o prestazioni da eseguire;
- indirizzo effettivo del servizio;
- comune;
- modalità di consegna del referto;
- data scelta tra le disponibilità effettive;
- eventuali ulteriori dati obbligatori applicabili al caso.

# Nome, cognome e codice fiscale

Nome e cognome devono riferirsi all’Assistito che effettua il prelievo.

Quando risultano chiaramente leggibili sulla prescrizione o da altra fonte affidabile già disponibile, possono essere utilizzati senza richiederli nuovamente.

Il codice fiscale è obbligatorio e può essere acquisito dalla prescrizione, dall’Assistito o da altra documentazione affidabile disponibile.

Non devono essere ricostruiti, completati o corretti autonomamente dati dubbi o illeggibili.

Se dati affidabili risultano discordanti e la discordanza non può essere chiarita, è necessaria la gestione del personale Casp.

# Recapito telefonico operativo

Deve essere disponibile un numero che consenta al personale Casp di contattare l’Assistito o la persona che organizza concretamente il servizio.

Può coincidere con il numero WhatsApp utilizzato per la conversazione. Se tale numero è già disponibile e corretto, non deve essere richiesto nuovamente.

Può appartenere all’Assistito, a un familiare, caregiver o altra persona di riferimento.

Se viene indicato un nuovo recapito, utilizzare l’ultimo numero confermato.

# Prenotazione effettuata da un’altra persona

La prenotazione può essere effettuata da una persona diversa dall’Assistito.

I dati sanitari e anagrafici devono riferirsi sempre all’Assistito.

Quando utile possono essere registrati nome, rapporto con l’Assistito e recapito della persona che gestisce concretamente il servizio.

# Prescrizione

La prescrizione deve essere gestita secondo i file dedicati a tipologia, validità ed esami disponibili.

Deve riferirsi all’Assistito ed essere amministrativamente gestibile.

I dati chiaramente leggibili devono essere utilizzati senza richiederli nuovamente.

# Assenza di prescrizione

Se l’Assistito non dispone di prescrizione, possono essere raccolti i dati utili, compresi dati anagrafici, recapito operativo ed esami desiderati.

La disponibilità degli esami deve essere verificata nella Knowledge Base.

Le prestazioni vengono gestite in regime privato o di solvenza secondo le regole economiche previste.

L’appuntamento non deve essere creato prima che il personale Casp abbia predisposto o gestito la prescrizione.

Dopo la gestione umana, il flusso riprende dal primo elemento ancora mancante senza richiedere nuovamente i dati già acquisiti.

# Ricetta elettronica o dematerializzata

Quando applicabile possono essere necessari:
- nome e cognome;
- codice fiscale;
- NRE;
- data di emissione;
- prestazioni e quantità;
- eventuale esenzione;
- altri dati amministrativi necessari.

Il NRE deve essere gestito esclusivamente secondo il file dedicato alle prescrizioni.

# Ricetta rossa SSN

Devono essere acquisiti esclusivamente i dati amministrativi applicabili al documento.

Non deve essere richiesto un NRE soltanto perché previsto per la ricetta dematerializzata.

# Prescrizione privata

Devono essere acquisiti i dati amministrativi applicabili.

Validità e gestione economica sono disciplinate rispettivamente dai file dedicati alla validità e ai costi.

# Esami da eseguire

Gli esami devono essere associati all’Assistito corretto.

Devono essere utilizzate soltanto le prestazioni effettivamente presenti e identificabili nella prescrizione oppure, nel flusso senza prescrizione, quelle esplicitamente richieste.

La disponibilità deve essere verificata secondo il file dedicato agli esami e il nomenclatore vigente.

Non devono essere aggiunti, eliminati o sostituiti esami, né interpretate abbreviazioni dubbie o create equivalenze mediche non previste.

# Esami con organizzazione speciale

Quando un esame è classificato come disponibile con organizzazione speciale, deve essere registrata la nota operativa necessaria.

La gestione successiva alla creazione dell’appuntamento è disciplinata dal System Prompt e dal file dedicato agli esami.

# Esenzione

Quando presente e chiaramente leggibile, l’esenzione può essere acquisita.

L’assenza di esenzione non costituisce un dato mancante.

L’esenzione non deve essere interpretata autonomamente. Applicabilità e trattamento economico sono disciplinati dal file dedicato ai costi.

# Indirizzo effettivo del servizio

Deve essere acquisito il luogo nel quale il prelievo verrà effettivamente eseguito.

Non deve essere utilizzato automaticamente l’indirizzo di residenza, quello riportato sulla prescrizione o quello della persona che prenota.

L’indirizzo deve comprendere, quando disponibili, via/piazza/contrada, numero civico e comune.

Il CAP è facoltativo quando indirizzo e comune sono già sufficientemente identificabili.

# Numero civico

Il numero civico deve essere registrato quando esiste.

Se il domicilio non ne dispone, non deve esserne inventato uno.

Quando l’assenza del civico determina l’applicazione delle regole sulla Posizione WhatsApp, devono essere seguite le procedure del file sulla copertura territoriale.

# Comune e copertura

Deve essere identificato con certezza il comune nel quale il servizio verrà eseguito.

Conta esclusivamente il luogo effettivo del prelievo.

La copertura territoriale deve essere verificata secondo il file dedicato.

# Posizione WhatsApp

Quando prevista dal file sulla copertura territoriale, la Posizione WhatsApp è obbligatoria.

Si applica in particolare a contrade, campagne, zone rurali, case sparse e altri casi espressamente previsti.

Non sono sostitutivi:
- link Google Maps;
- coordinate scritte manualmente;
- fotografie;
- descrizioni testuali;
- punti di riferimento.

Le coordinate eventualmente inserite in Calendar CUP devono derivare dalla Posizione WhatsApp effettivamente ricevuta e non dall’indirizzo o da coordinate scritte manualmente.

# Informazioni di accesso

Devono essere raccolte solo quando effettivamente utili.

Possono comprendere:
- piano;
- ascensore;
- nome sul citofono;
- cancello;
- ingresso specifico;
- strada privata;
- indicazioni indispensabili;
- difficoltà di accesso.

Non devono essere richiesti sistematicamente dati non pertinenti.

# Animali e sicurezza dell’accesso

La presenza di animali può essere registrata come nota operativa quando può interferire con l’accesso sicuro del personale.

L’informazione deve essere utilizzata esclusivamente per organizzazione e sicurezza.

# Persona di riferimento

Quando necessario possono essere registrati nome, rapporto con l’Assistito e recapito telefonico della persona di riferimento.

Questi dati devono essere raccolti soltanto quando utili alla concreta gestione del servizio.

# Modalità di consegna del referto

Per ogni nuova prenotazione deve essere registrata la modalità scelta dall’Assistito.

Le modalità disponibili sono disciplinate dal file dedicato ai referti.

Se viene scelta l’email, deve essere acquisito e confermato l’indirizzo email.

Se viene scelto WhatsApp, deve essere identificato il numero destinato alla ricezione del referto.

Se viene scelta la consegna cartacea, devono essere disponibili i dati necessari alla consegna.

Se l’Assistito sceglie esclusivamente il Fascicolo Sanitario Elettronico, tale scelta deve essere registrata.

# Indirizzo email

L’indirizzo email è necessario soltanto quando la modalità scelta lo richiede.

Deve essere riportato esattamente come comunicato, ripetuto all’Assistito e confermato.

Non deve essere corretto autonomamente.

# Preparazione agli esami

Prima della creazione devono essere identificate e comunicate le istruzioni essenziali applicabili agli esami richiesti.

Le istruzioni sono disciplinate dal file dedicato alla preparazione e raccolta dei campioni.

La preparazione è un’informazione da comunicare, non un dato anagrafico da raccogliere.

# Informazioni economiche

Prima della conferma finale devono essere comunicate le informazioni economiche applicabili.

Possono comprendere:
- costo del servizio Casp;
- eventuale stima del ticket SSN;
- eventuale costo degli esami in solvenza;
- eventuali costi aggiuntivi espressamente previsti;
- modalità di pagamento.

Gli importi sono disciplinati dal file dedicato a costi, tariffe e pagamenti.

# Data dell’appuntamento

La data deve essere scelta esclusivamente tra le disponibilità presenti nel file delle disponibilità, nel rispetto delle policy del file dedicato.

Il file delle disponibilità è la source of truth delle date proponibili. `Calendar CUP` non deve essere usato per cercare o dedurre disponibilità.

Le regole su giorno stesso, giorno successivo, date future e fascia oraria indicativa sono disciplinate dal file dedicato alle disponibilità.

# Preferenza oraria

L’Assistito può comunicare una preferenza per un passaggio più anticipato o tardivo.

Può essere registrata come nota operativa ma non costituisce un orario garantito.

# Note operative

Possono essere registrate esclusivamente informazioni utili all’organizzazione o all’esecuzione del servizio, tra cui quando applicabili:
- difficoltà di accesso;
- PICC, Midline, Port-a-Cath, CVC o altro dispositivo venoso;
- difficoltà nel reperimento dell’accesso venoso;
- Assistito allettato;
- difficoltà motorie;
- presenza di animali;
- preferenza oraria;
- persona di riferimento;
- organizzazione di esami speciali.

# Informazioni cliniche

Non deve essere acquisita una storia clinica generale.

Devono essere raccolte soltanto le informazioni sanitarie necessarie per una specifica procedura prevista dalla Knowledge Base.

Non devono essere richieste genericamente diagnosi, patologie, terapie o anamnesi.

Le informazioni cliniche spontaneamente comunicate non devono essere utilizzate per formulare diagnosi, valutazioni o consigli.

# Più Assistiti nello stesso domicilio

Ogni Assistito deve mantenere una prenotazione separata.

Per ciascuno devono restare distinti:
- nome e cognome;
- codice fiscale;
- prescrizioni;
- NRE;
- prestazioni;
- esenzioni;
- modalità di consegna del referto;
- note individuali.

Possono essere condivisi, quando comuni:
- indirizzo;
- Posizione WhatsApp;
- informazioni di accesso;
- recapito organizzativo.

# Elementi necessari prima della creazione

Prima del create devono risultare disponibili e gestiti, quando applicabili:
- identificazione corretta dell’Assistito;
- codice fiscale;
- recapito telefonico operativo;
- prescrizione amministrativamente gestibile;
- dati amministrativi necessari della prescrizione;
- esami da effettuare e relativa disponibilità;
- indirizzo effettivo, comune e copertura;
- Posizione WhatsApp quando obbligatoria;
- informazioni indispensabili per l’accesso;
- modalità di consegna del referto e relativi dati;
- note operative obbligatorie;
- istruzioni essenziali di preparazione comunicate;
- informazioni economiche comunicate;
- data scelta tra le disponibilità effettive;
- conferma finale dell’Assistito.

L’appuntamento non deve essere creato finché gli elementi applicabili non sono completi.

# Modifica di un dato prima della creazione

Se prima del create l’Assistito modifica un dato, utilizzare l’ultimo valore confermato ed effettuare nuovamente le verifiche eventualmente necessarie.

Esempi:
- nuovo indirizzo → nuova verifica della copertura;
- nuovo comune → nuova verifica territoriale e della disponibilità;
- nuova data → nuova verifica della disponibilità;
- nuova prescrizione → nuove verifiche amministrative e degli esami;
- nuova modalità di referto → acquisizione dei dati richiesti.

# Appuntamento già creato

Questo file disciplina i dati necessari per una nuova prenotazione.

Dopo la creazione, le modifiche ai dati registrati non devono essere effettuate autonomamente.

Si applicano le regole del file dedicato a modifica, spostamento e cancellazione.

# Riutilizzo delle informazioni già disponibili

Un dato affidabile già disponibile non deve essere richiesto nuovamente.

Possono essere riutilizzati dati stabili come nome, cognome, codice fiscale e recapiti confermati.

I dati potenzialmente variabili devono essere gestiti secondo il System Prompt.

Non devono essere automaticamente riutilizzati per una nuova prenotazione:
- prescrizione;
- NRE;
- esami;
- esenzione;
- data precedente;
- preparazione precedente;
- precedente calcolo del ticket.

# Correzione delle informazioni

Prima della creazione, l’ultima informazione chiaramente confermata sostituisce quella precedente.

Non devono rimanere contemporaneamente attivi dati incompatibili riferiti allo stesso elemento.

# Regola finale

Questo file stabilisce quali informazioni sono necessarie o possono diventare necessarie per una nuova prenotazione.

Il System Prompt stabilisce ordine, momento delle domande, riutilizzo dei dati, trasferimento al personale e creazione tramite Calendar CUP.

La prenotazione può essere creata soltanto quando tutti gli elementi applicabili risultano completi, verificati e confermati.
