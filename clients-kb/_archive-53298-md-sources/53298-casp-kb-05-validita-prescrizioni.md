# Validità delle prescrizioni

## Regola generale

La validità amministrativa della prescrizione deve essere verificata prima della creazione di una nuova prenotazione.

La verifica deve basarsi esclusivamente:

- sulla tipologia di prescrizione;
- sulla data di emissione, quando prevista;
- sulle informazioni effettivamente presenti nel documento;
- sulle regole indicate nella Knowledge Base.

La validità clinica, l’appropriatezza e la necessità degli esami non rientrano nella verifica amministrativa.

Se la validità amministrativa non può essere determinata con sufficiente certezza, è necessaria la valutazione del personale Casp.

# Data di riferimento per la validità

Ai fini del servizio Casp, la validità temporale della prescrizione viene verificata alla data in cui viene effettuata la prenotazione.

Se la prescrizione è ancora valida il giorno in cui viene completata la prenotazione, può essere utilizzata anche quando la data successivamente scelta per il prelievo cade oltre il periodo ordinario di validità della prescrizione.

Pertanto, ai fini della validità della prescrizione:

data rilevante = data della prenotazione;

non è necessario che la prescrizione risulti ancora valida anche il giorno del prelievo.

# Ricetta elettronica o dematerializzata SSN

La ricetta elettronica o dematerializzata del Servizio Sanitario Nazionale è considerata valida per:

180 giorni dalla data di emissione.

La prescrizione può essere utilizzata per una nuova prenotazione quando, alla data della prenotazione, non ha superato il periodo di validità di 180 giorni.

Se il periodo previsto risulta chiaramente superato, la prescrizione non deve essere utilizzata autonomamente per creare una nuova prenotazione e il caso necessita della valutazione del personale Casp.

# Ricetta rossa SSN

La ricetta rossa del Servizio Sanitario Nazionale è considerata valida per:

180 giorni dalla data di emissione.

Si applicano le stesse regole temporali previste per la prescrizione dematerializzata.

La prescrizione può essere utilizzata per una nuova prenotazione quando, alla data della prenotazione, non ha superato il periodo di validità di 180 giorni.

Se il periodo previsto risulta chiaramente superato, il caso necessita della valutazione del personale Casp.

# Prescrizione privata o in solvenza

Per politica organizzativa del Casp, una prescrizione medica privata datata è considerata utilizzabile entro:

2 anni dalla data riportata sulla prescrizione.

Il periodo di 2 anni costituisce una regola adottata dal Casp per la gestione del proprio servizio e non deve essere presentato come una regola generale di legge.

Se la prescrizione privata datata ha superato il periodo di 2 anni alla data della prenotazione, il caso necessita della valutazione del personale Casp.

# Prescrizione privata senza data

Una prescrizione medica privata priva di data viene considerata valida secondo la politica organizzativa del Casp.

L’assenza della data, da sola, non determina quindi il trasferimento al personale Casp e non impedisce autonomamente la prenotazione.

Non deve essere attribuita, ricostruita o inventata una data di emissione.

Questa eccezione riguarda esclusivamente le prescrizioni private.

Una prescrizione SSN per la quale la data necessaria alla verifica della validità non è leggibile o identificabile necessita invece della valutazione del personale Casp.

# Prescrizione prossima alla scadenza

Una prescrizione ancora valida può essere utilizzata normalmente anche quando è prossima alla scadenza.

La vicinanza alla scadenza:

- non determina una priorità;
- non genera un’urgenza;
- non modifica le normali disponibilità;
- non richiede di anticipare il prelievo.

Se la prescrizione è valida alla data della prenotazione, il normale flusso può proseguire.

# Prescrizione scaduta

Quando una prescrizione risulta chiaramente oltre il periodo di validità previsto dalla Knowledge Base, non deve essere utilizzata autonomamente per creare una nuova prenotazione.

Il caso deve essere sottoposto al personale Casp.

Non deve essere dichiarato autonomamente che la prescrizione sarà sicuramente inutilizzabile, sostituibile o comunque accettata.

Non devono essere suggeriti metodi per aggirare la scadenza.

# Data non leggibile o dubbia

Quando la validità dipende dalla data di emissione, la data deve essere ricavata esclusivamente dalla prescrizione.

Se la data è:

- illeggibile;
- incompleta;
- ambigua;
- apparentemente alterata;

può essere richiesto un nuovo invio leggibile secondo le regole di gestione documentale.

Se il nuovo documento non consente comunque di determinare la data necessaria, è richiesta la valutazione del personale Casp.

La data non deve essere ricostruita sulla base:

- del giorno in cui il documento è stato inviato su WhatsApp;
- delle dichiarazioni dell’Assistito;
- della data della fotografia;
- di informazioni dedotte dal contesto.

Fa eccezione esclusivamente la prescrizione privata senza data, che è gestita secondo la specifica politica Casp indicata in questo file.

# Data futura o impossibile

Se la data riportata sulla prescrizione appare successiva alla data corrente, impossibile o manifestamente incoerente, la prescrizione non deve essere utilizzata autonomamente.

La data corrente deve essere verificata prima di concludere che vi sia una discordanza.

Se l’anomalia viene confermata, il caso necessita della valutazione del personale Casp.

# Calcolo della validità

Quando è presente una data di emissione leggibile e la Knowledge Base stabilisce un periodo di validità preciso, la validità può essere determinata confrontando la data di emissione con la data della prenotazione.

Per le prescrizioni SSN:

periodo massimo = 180 giorni.

Per le prescrizioni private datate:

periodo massimo Casp = 2 anni.

Per le prescrizioni private senza data si applica la specifica eccezione prevista in questo file.

Per riferimenti temporali relativi come “oggi”, “domani” o “questa settimana”, deve essere utilizzata la data corrente effettiva.

# Prescrizione già utilizzata

Una prescrizione dichiarata già utilizzata integralmente non deve essere automaticamente riutilizzata per una nuova prenotazione.

È necessaria la valutazione del personale Casp.

La stessa regola si applica quando la prescrizione risulta già associata a una precedente prestazione o prenotazione e non è chiaro se sia ancora utilizzabile.

# Prescrizione utilizzata parzialmente

Se l’Assistito dichiara che una prescrizione è stata utilizzata soltanto in parte, non deve essere stabilito autonomamente se le prestazioni residue possano essere utilizzate.

Il caso necessita della valutazione del personale Casp.

# Prescrizione annullata

Una prescrizione dichiarata annullata dal medico, dal sistema sanitario, dal CUP o da altra struttura non deve essere utilizzata autonomamente per una nuova prenotazione.

È necessaria la valutazione del personale Casp.

# Prescrizione ristampata

La ristampa di una ricetta elettronica che presenta lo stesso NRE della prescrizione già acquisita rappresenta la stessa prescrizione e non una nuova ricetta.

Non deve quindi essere conteggiata o gestita come una prescrizione aggiuntiva.

Se i documenti apparentemente identici riportano NRE differenti, devono essere trattati come prescrizioni distinte salvo diversa indicazione chiaramente verificabile.

# Prescrizioni apparentemente duplicate

Quando vengono ricevuti due documenti apparentemente identici, deve essere verificato se rappresentano la stessa prescrizione o prescrizioni distinte.

Per le ricette elettroniche, la coincidenza del NRE identifica la stessa prescrizione.

In presenza di informazioni non sufficienti per distinguere con certezza i documenti, è necessaria la valutazione del personale Casp.

# NRE e validità

La presenza di un NRE non costituisce da sola conferma della validità amministrativa della ricetta.

La prescrizione deve comunque rispettare le regole temporali e amministrative previste dalla Knowledge Base.

La gestione della leggibilità e della conferma del NRE è disciplinata dal file dedicato alle prescrizioni accettate e alla gestione delle ricette.

# Prescrizione con più prestazioni

Quando una singola prescrizione contiene più prestazioni, la validità temporale viene verificata sulla prescrizione nel suo complesso.

Non devono essere attribuite autonomamente date di scadenza differenti alle singole prestazioni presenti sulla stessa prescrizione.

# Classe di priorità

La presenza di una classe di priorità sulla prescrizione non modifica il periodo di validità indicato in questo file.

La classe di priorità non determina autonomamente date diverse da quelle previste dal file dedicato alle disponibilità.

# Esenzione

La presenza o l’assenza di un codice di esenzione non modifica automaticamente la validità temporale della prescrizione.

Le regole economiche relative all’esenzione sono contenute nel file dedicato a costi, tariffe e modalità di pagamento.

# Correzioni, cancellature e anomalie

Una prescrizione che presenta:

- cancellature;
- correzioni manuali;
- sovrascritture;
- data modificata;
- NRE alterato;
- dati modificati;
- altre anomalie rilevanti;

non deve essere valutata autonomamente come valida.

È necessaria la valutazione del personale Casp.

Le prescrizioni contenenti informazioni manoscritte sono inoltre soggette alle regole previste nel file dedicato alla gestione delle prescrizioni.

# Dati incoerenti

Se la prescrizione presenta informazioni tra loro incoerenti, il documento non deve essere corretto o reinterpretato autonomamente.

Sono esempi di incoerenza:

- data impossibile;
- data futura;
- più date incompatibili;
- dati dell’Assistito discordanti;
- prescrizione apparentemente riferita a un’altra persona;
- altre incongruenze che impediscono una verifica amministrativa certa.

In questi casi è necessaria la valutazione del personale Casp.

# Prescrizione sostituita dal medico

Se il medico ha emesso una nuova prescrizione in sostituzione di una precedente, per una prenotazione non ancora creata deve essere utilizzata l’ultima prescrizione valida fornita dall’Assistito.

La prescrizione sostituita non deve essere utilizzata per la nuova prenotazione.

La nuova prescrizione deve essere sottoposta alle normali verifiche di tipologia, validità, prestazioni e disponibilità.

# Prescrizione sostituita dopo la creazione dell’appuntamento

Se esiste già un appuntamento creato e l’Assistito comunica che una prescrizione è stata sostituita, modificata o deve essere cambiata, la richiesta deve essere gestita dal personale Casp.

L’appuntamento esistente non deve essere modificato autonomamente.

Non deve essere:

- sostituita autonomamente la prescrizione associata;
- modificato l’appuntamento tramite Calendar CUP;
- cancellato l’appuntamento;
- creato un nuovo appuntamento sostitutivo.

Questa regola si applica a qualsiasi modifica delle prescrizioni successiva alla creazione dell’appuntamento.

# Prescrizione valida amministrativamente ma dubbia clinicamente

La verifica effettuata ai fini della prenotazione riguarda esclusivamente la validità amministrativa.

Non deve essere stabilito autonomamente:

- se gli esami siano ancora necessari;
- se la prescrizione sia clinicamente appropriata;
- se il medico avrebbe dovuto prescrivere esami diversi;
- se una prescrizione clinicamente datata debba essere rifatta nonostante sia amministrativamente valida.

Le valutazioni cliniche spettano al medico o al professionista sanitario competente.

# Regola finale

Per una nuova prenotazione:

- ricetta dematerializzata SSN: 180 giorni dalla data di emissione;
- ricetta rossa SSN: 180 giorni dalla data di emissione;
- prescrizione privata datata: 2 anni dalla data, per politica Casp;
- prescrizione privata senza data: considerata valida per politica Casp.

La validità temporale viene verificata alla data della prenotazione e non alla data successiva del prelievo.

Una prescrizione ancora valida ma prossima alla scadenza può essere prenotata normalmente.

Prescrizioni scadute, già utilizzate, parzialmente utilizzate, annullate, anomale o la cui validità non sia determinabile con sufficiente certezza necessitano della valutazione del personale Casp.

Per un appuntamento già creato, qualsiasi sostituzione o modifica della prescrizione deve essere gestita dal personale Casp.
